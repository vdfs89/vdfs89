VektorWork

Dois pipelines multiagente atrás de uma API: um lê seu CV e uma vaga para planejar a candidatura, o outro transforma o briefing de um cliente numa proposta técnica. Só o segundo tem permissão para chamar a nuvem.

Dados de carreira (CV, pretensão salarial) são o que há de mais sensível que alguém em busca de emprego compartilha, e a maioria das ferramentas de IA manda isso para uma API de terceiros. O VektorWork faz da execução local uma regra imposta no código, não uma configuração, e transmite o progresso de cada agente para clientes Flutter e Electron.

Arquitetura

Dois grafos,
duas regras de privacidade.

Os dois pipelines são grafos de estado do LangGraph que terminam num agente revisor. No grafo freelance, o revisor também pode devolver o trabalho antes de qualquer coisa ser salva.

Decisões de engenharia

Três decisões que valem explicar
numa entrevista.

01 · Privacidade

Só local como exceção, não como opção.

Uma política de execução define quais provedores cada modo pode usar. No modo carreira, o analisador de aderência valida o provedor contra ela, e qualquer coisa que não seja o Ollama levanta uma violação de privacidade em vez de mandar o CV para fora. Uma variável de ambiente mal configurada falha alto em vez de vazar.

Hoje a checagem fica nesse agente; aplicá-la a todos os agentes do grafo é o próximo passo.

02 · Qualidade

Um revisor que pode dizer não.

O grafo freelance termina num revisor com uma aresta condicional: trabalho aprovado vai para a memória, trabalho rejeitado volta ao gerente de produto para mais uma passada. Gerar a proposta e julgá-la são agentes separados, com prompts separados.

03 · Estado

Execuções para as quais dá para voltar.

O estado do grafo é salvo em SQLite com o checkpointer assíncrono do LangGraph, então o studio lista execuções anteriores e as reabre, e o progresso dos agentes é transmitido aos clientes por WebSocket enquanto a execução acontece.

Limitações

O que este projeto
não é.

  • Modelos locais são mais lentos e mais fracos que os da nuvem; o modo carreira troca qualidade de resposta por manter os dados na máquina.
  • O repositório é privado e a plataforma não é pública; não há demo hospedada.
  • A qualidade das saídas não foi comparada com um conjunto de referência, então esta página não cita números de qualidade.
