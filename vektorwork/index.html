VektorWork

Two multi-agent pipelines behind one API: one reads your CV and a job post to plan an application, the other turns a client brief into a technical proposal. Only the second is allowed to call the cloud.

Career data (CVs, salary expectations) is the most sensitive thing a job seeker shares, and most AI tools send it to a third-party API. VektorWork makes local execution a rule enforced in code, not a setting, and streams each agent's progress to Flutter and Electron clients.

Architecture

Two graphs,
two privacy rules.

Both pipelines are LangGraph state graphs that end in a reviewer agent. In the freelance graph, the reviewer can also send the work back before anything is saved.

Engineering decisions

Three calls worth explaining
in an interview.

01 · Privacy

Local-only as an exception, not a toggle.

An execution policy defines which providers each mode may use. In career mode, the job-fit analyzer validates its provider against it, and anything other than Ollama raises a privacy violation instead of sending the CV out. A misconfigured environment variable fails loudly rather than leaking.

Today the check lives in that agent; applying it to every agent of the graph is the next step.

02 · Quality

A reviewer that can say no.

The freelance graph ends in a reviewer with a conditional edge: approved work goes to memory, rejected work goes back to the product manager for another pass. Generating a proposal and judging it are separate agents with separate prompts.

03 · State

Runs you can come back to.

Graph state is checkpointed to SQLite with LangGraph's async saver, so the studio can list past runs and reopen them, and agent progress is streamed to the clients over WebSockets while a run is in flight.

Limitations

What this project
is not.

  • Local models are slower and weaker than cloud ones; the career mode trades answer quality for keeping the data on the machine.
  • The repository is private and the platform is not public; there is no hosted demo.
  • Output quality has not been benchmarked against a reference set, so this page quotes no quality numbers.
